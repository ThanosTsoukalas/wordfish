# WordFish
WordFish is a word predictor at best, with its own training and prediction algorithm. It has a very humble feature set for now, and segfaults a lot, but what it can do is quite impressive for
the few lines of code I've written for it.

It can:
 - Predict the next word you give it based on the training set
 - Make a tree of nodes and words just from that training set
 - Yeah, that's all, sorry.

I am planning to make this a full featured mini-gpt tool that you can use locally for everyday tasks. I will not further enhance the training data, since I don't want to infringe on people's hard worked creations. This tool is absolutely not made to be used as a more sophisticated plagiarism machine. This is how I envision AI to be used, and if someone wants to use it a different way, they are welcome to provide their own training data, and use the AI for personal use. But remember that using works of people without their consent in any way is immoral, and, at best, illegal. This project is for personal use only, and can only be used in commercial software after my written consent.
